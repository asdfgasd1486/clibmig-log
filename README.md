# clibmig-log — 登山計画書メーカー

登山**前**に作る「登山計画書」を作成・保存し、印刷／PDF保存できる静的Webサイトです。
サーバー不要で、`index.html` をブラウザで開くか GitHub Pages などにそのまま置けば動きます。

**公開URL：** https://asdfgasd1486.github.io/clibmig-log/

## できること

- **基本情報**：山の名前、都道府県（47都道府県から選択）、登山日・下山予定日・予備日、山行形態、山域、登山口、交通手段
- **メンバー**：役割・氏名・年齢・性別・携帯電話・緊急連絡先
- **行程（コースタイム）**：地点・標高・予定時刻を入力すると自動計算
  - 最高地点／**高低差**（最高標高−最低標高）
  - 累積標高（上り・下り）
  - **登山（行動）時間**（日ごとの最初〜最後の予定時刻の合計）
  - 地図アプリなどの値があれば手入力で上書き可能
- **カロリー・水分（1人あたり）**
  - **消費カロリー**：山本正嘉氏の推定式
    `(1.8×行動時間[h] + 0.3×歩行距離[km] + 10×上り累積[km] + 0.6×下り累積[km]) × (体重+荷物重量)[kg]`
  - **摂取カロリー**：食料リスト（食事・行動食）の合計と、消費との差し引き
  - **非常食**：摂取計画とは別に集計
  - 必要水分：`5mL × (体重+荷物) × 行動時間` と持参量の比較
- **装備チェックリスト**、エスケープルート、提出先、山岳保険、備考
- **計画書プレビュー**（A4レイアウト）
  - 「印刷 / PDFとして保存」：ブラウザの印刷ダイアログ（送信先「PDFに保存」）
  - 「PDFをダウンロード」：A4のPDFファイルを直接保存（[html2pdf.js](https://github.com/eKoopmans/html2pdf.js) を同梱）
- 計画の一覧・複製・削除、JSONでのバックアップ／読み込み

データはブラウザの localStorage に自動保存されます（サーバーには送信されません）。

## ファイル構成

```
index.html                         画面（一覧／編集／計画書）
css/style.css                      スタイル（印刷用CSSを含む）
js/app.js                          アプリ本体
js/vendor/html2pdf.bundle.min.js   PDF直接出力用ライブラリ（MIT）
```

## ローカルで確認

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

「サンプルを追加」で北岳の山小屋泊プランが入るので、動作確認に使えます。

> ※ カロリー・水分量はあくまで目安です。実際の計画では体調・気象・ルート状況を考慮してください。
